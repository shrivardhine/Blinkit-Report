
Blinkit Sales Report Project
Project Overview
This project showcases a comprehensive analysis of Blinkit’s sales performance, customer satisfaction, and inventory distribution using Excel. The objective was to extract actionable insights and visualize them in an interactive dashboard to aid decision-making.

Dataset
Source:  Blinkit dataset in CSV format.

Key Features
Data Cleaning:

Standardized fat content values (e.g., "LF" -> "Low Fat", "reg" -> "Regular").
Addressed missing/null values in critical columns like Date and Total Sales.
KPIs Tracked:

Total Sales: Overall revenue from sold items.
Average Sales: Revenue per sale.
Number of Items Sold: Count of different items sold.
Average Rating: Customer satisfaction score (1–5 scale).
Dashboard Highlights:

KPI Cards for quick metrics.
Donut Charts to visualize fat content distribution.
Bar Charts for sales by item type and outlet location.
Area Chart for outlet size performance.
Interactive Elements:

Slicers for dynamic filtering.
Buttons for sheet navigation.
Insights & Recommendations
Sales & Orders:

Tier 3 cities contributed the highest sales and orders, highlighting growth potential in smaller cities.
Supermarket Type 1 outlets dominated sales and customer engagement.
Item Categories:

Fruits, Vegetables, and Snacks performed exceptionally well.
Seafood needs attention due to low sales and orders.
Customer Satisfaction:

Average rating: 4/5, with 55% of orders rated 4 and 37% rated 5.
Focus on enhancing quality and service to maintain satisfaction.
Other Key Findings:

64% of products sold were "Regular" fat content.
Average sales per order: ₹141.
Real-World Applications
Market Expansion: Focus on Tier 3 cities and top-performing outlet types.
Product Optimization: Promote high-demand categories; strategize for low-performing ones.
Customer Retention: Improve ratings with better service and quality.
Inventory Management: Optimize stock levels based on demand patterns.
Tools & Techniques
Tools Used: Microsoft Excel (Pivot Tables, Charts, Slicers).
Skills Applied: Data Cleaning, Data Transformation, KPI Analysis, Dashboard Design, and Data Visualization.
